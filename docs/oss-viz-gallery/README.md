# OSS 可视化效果预览

独立 ECharts 图库，用来在浏览器里预览本 fork 新增图表和柱线饼动效。**不是** Metabase 本体，也不是企业版实现。

## 打开

需要能访问 CDN（cdnjs 上的 ECharts 5）：

```bash
cd docs/oss-viz-gallery
python3 -m http.server 8765
```

浏览器打开 http://127.0.0.1:8765/

## 页面上有什么

- 现有图加强动效：柱状图、折线图、饼图
- 第一批新图：雷达、矩阵热力、旭日、玫瑰、日历热力
- 日常常见补齐：环形、气泡、词云、子弹图、直方图、径向柱、棒棒糖、水球、华夫、帕累托、气泡树、关系图、甘特、K 线、人口金字塔

右上角可切换 **浅色 / 深色**。图表轴、标签、热力色带会跟着主题走。

样例数据是虚构的零售/SaaS 运营数据。
